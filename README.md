# COMEBACK OS v1.0

A phone-first JEE preparation tracker prototype.

## Run
Extract the ZIP and open `index.html` in a browser. For installability and offline app behavior, host the files on an HTTPS static host (for example, GitHub Pages), then open the site in Chrome and choose **Add to Home screen**.

## Included
- Home dashboard and XP/level display
- Daily quests and study-session log
- 30 initial chapter records with priority flags
- Separate JEE Main and JEE Advanced verification toggles
- Planner tasks
- JSON export/import backup
- Local browser storage

## Important limitations
This is an early prototype, not the complete COMEBACK OS. It does not yet include cloud sync, a full official syllabus audit, automated question grading, the 21-day grade engine, Academic Power calculations, retention assessments, squads/titles/weapon evolution, or notification scheduling. PYQ verification toggles are user-entered records, not automatic validation. Export backups regularly; clearing browser data may erase local records.

XP values and level thresholds are provisional. Repeated completion of the same quest does not award XP again after its first completion.
